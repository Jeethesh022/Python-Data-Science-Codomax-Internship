# Module 5 – Olympic Games Data Analysis

## Project Overview

This project analyzes historical Olympic Games data to identify meaningful patterns and insights related to athletes, countries, sports, medals, events, and participation.

The analysis was performed using Python, Pandas, NumPy, and Matplotlib.

## Dataset

The project uses the "120 Years of Olympic History" dataset.

The main dataset contains information about:

- Athletes
- Countries / NOCs
- Sports
- Events
- Olympic years
- Age
- Height
- Weight
- Medals

## Analysis Performed

The project includes:

- Dataset structure and data types
- Missing value analysis
- Statistical summary
- Country-wise participation
- Unique athlete participation by sport
- Overall medal distribution
- Country-wise medal analysis
- Gold medal analysis
- Athlete age distribution
- Height and weight relationship
- Olympic participation over the years
- Most participated Olympic events
- India's Olympic medal records

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Kaggle Dataset

## Key Outcome

The project demonstrates how exploratory data analysis can be used to understand a large real-world dataset and extract useful insights through data analysis and visualization.
