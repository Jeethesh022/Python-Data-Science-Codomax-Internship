# Module 6 – LandInsight: Land Price Prediction

## Overview
LandInsight is a Machine Learning project that predicts estimated land prices using property details and location-related features.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Project Workflow
1. Data preprocessing
2. Exploratory Data Analysis
3. Feature preparation
4. Machine Learning model training
5. Model evaluation
6. Sample land price prediction

## Model
Gradient Boosting Regressor

## Outcome
The project estimates land price per square foot and the total land price based on the selected land details.

## Learning Outcomes
- Data analysis and preprocessing
- Regression modelling
- Machine Learning prediction
- Model evaluation

## Conclusion
This project demonstrates the application of Machine Learning to land price estimation. The output is an estimate and not an official property valuation.
