# Module 4 – Machine Learning Basics

## Project: Gold Rate Prediction

This module focuses on the basics of Machine Learning using Python and Scikit-learn.

### Topics Covered

- Feature and target selection
- Train-test split

- Model training
- Prediction

- Testing with new data
- Feature coefficients

Gold Rate Prediction using financial and economic factors.

- Python
- Pandas
- NumPy

- Google Colab
